Askovo

See how real evidence changes a decision

No install: open the Decision Brief ↗Product & documentation ↗
STABLE
pipx install askovo==2.25.2
askovo demo
PREVIEW
pipx install askovo==2.25.2
askovo demo

Synthetic samples verify installation only; each channel has a separate capability promise.

FIRST REAL TASK
askovo decide start --input task.json
askovo decide status TASK_ID
askovo decide brief TASK_ID --format md

Put a consequential product decision, owner and authorized sources in `task.json`. Unauthorized collection stops instead of producing a synthetic answer.

PREVIEW

Synthetic samples verify installation. Channel, account and platform permission stay separate.

FIRST REAL TASK
mkt growth intake --repo /path/to/repository \
  --slug owner/repo --read-metrics --out intake-goal.json
mkt growth start --file intake-goal.json
mkt growth run SERVICE_ID --action diagnose-product --by "$USER"

Read a real repository and produce a business diagnosis. External writes need separate authorization; the first task never posts automatically.

Verovo

See how a charge gets independently checked

No install: open the replayable period ↗Product & documentation ↗
STABLE
pipx install verovo==1.0.0
verovo review --sample
PREVIEW
pipx install verovo==1.0.0
verovo review --sample

Synthetic samples verify installation. Charges, bills, controls and realized savings stay on separate evidence levels.

FIRST REAL TASK
verovo check --days 7
verovo tool-value --economics-case task-case.json --json

`check` discovers accessible local agent logs and reports when none exist. Economics comparisons use real task records; incomplete cost or acceptance coverage remains unknown.

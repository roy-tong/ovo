# OVO

让通用 Agent 把真实业务做成。三个独立开源产品，提供可组合的专业能力：

| 产品 | 真实交付 |
| --- | --- |
| [Askovo](https://github.com/roy-tong/Askovo) | 真实研究证据、反证和可复审的产品决定 |
| [Growovo](https://github.com/roy-tong/Growovo) | 授权内的持续运营、业务回执和后续行动 |
| [Verovo](https://github.com/roy-tong/Verovo) | 独立经济事实、工具比较和优化复核 |

**官网**：[中文](https://roy-tong.github.io/ovo/) · [English](https://roy-tong.github.io/ovo/en.html) · [案例与 Demo](https://roy-tong.github.io/ovo/cases.html) · [快速开始](https://roy-tong.github.io/ovo/start.html)

当前预发行版本：Askovo `2.25.1rc1`、Growovo `0.23.1rc2`、Verovo `0.20.1rc2`。本地 Demo 使用合成数据，公开案例保留来源、负结果和 unknown，不把功能演示写成外部采用。

## 本地预览

网站使用双语静态 HTML、本地字体、CSS 和 JavaScript，无需构建：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。发布前检查中英文文案、交互 Demo、筛选、减少动态效果设置、移动导航和所有链接。

## OVO in English

OVO gives general agents the real-world capabilities they cannot get from a prompt alone:

| Product | What it delivers |
| --- | --- |
| [Askovo](https://github.com/roy-tong/Askovo) | Real research evidence, counterevidence and reviewable product decisions |
| [Growovo](https://github.com/roy-tong/Growovo) | Authorized continuous operations, business receipts and next actions |
| [Verovo](https://github.com/roy-tong/Verovo) | Independent economic facts, tool comparisons and optimization review |

**Website**: [English](https://roy-tong.github.io/ovo/en.html) · [中文](https://roy-tong.github.io/ovo/) · [Cases & demos](https://roy-tong.github.io/ovo/en-cases.html) · [Get started](https://roy-tong.github.io/ovo/en-start.html)

Current prereleases: Askovo `2.25.1rc1`, Growovo `0.23.1rc2` and Verovo `0.20.1rc2`. Local demos use synthetic data. Public cases preserve sources, negative results and unknowns; a feature demo is not external adoption.

Run the same preview command above, then check both languages, demo interactions, filters, reduced-motion support, mobile navigation and links before publishing.

# OVO

Three independent open-source tools for product research, growth operations and AI spend verification.

[Website](https://roy-tong.github.io/ovo/en.html) · [中文](https://roy-tong.github.io/ovo/) · [Cases and demos](https://roy-tong.github.io/ovo/en-cases.html) · [Get started](https://roy-tong.github.io/ovo/en-start.html)

| Project | What it delivers |
| --- | --- |
| [Askovo](https://github.com/roy-tong/Askovo) | A research decision with sources, counterexamples and a review history |
| [Growovo](https://github.com/roy-tong/Growovo) | Authorized growth actions with receipts, replies and follow-up records |
| [Verovo](https://github.com/roy-tong/Verovo) | An independent check of supplier charges and the costs of accepted work |

## Website

Bilingual static HTML, local fonts, CSS and JavaScript. The site works on GitHub Pages without a build step. To preview from this directory, run `python3 -m http.server 4173 --bind 127.0.0.1`.

Public case studies link to original sources. Interactive examples use sample data and run in the browser. The getting-started pages include commands for running the actual product demos locally.

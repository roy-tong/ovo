不是指定你用 OVO，而是看 Agent 是否愿意选择 OVO

  • 原生 Agent先测模型本身能否完成真实任务，建立能力基线。
  • 成熟第三方工具与团队已经使用的搜索、浏览器、网关和研究工具比较。
  • 指定使用 OVO测量接入后增加了多少真实交付与证据。
  • 可自由选择 OVO观察 Agent 是否发现、安装、选择并再次使用，而不是被提示词强迫。
A · Native Agent通用 Agent 与原生工具，测模型本身的业务能力。
B · Existing Stack通用 Agent 加成熟第三方工具，测现实替代方案。
C · OVO Directed明确指定使用 OVO，测产品的业务增量价值。
D · OVO Available允许选择不同能力，测主动发现、选择与复用。

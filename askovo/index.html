ASKOVO · REAL RESEARCH

先验证真正影响研发投入的问题。

面向创始人、产品经理和用户研究员。输入一项真实产品决定和现有材料，获得原始证据、反例、决定简报与后续复审入口；不是再生成一份通用研究文档。

第一项真实任务

在 `task.json` 写入产品决定、负责人、授权来源和预算。未授权采集会停止，合成材料不会冒充实证。

源码与完整文档 ↗
REAL TASK
askovo decide start --input task.json
askovo decide status TASK_ID
askovo decide brief TASK_ID --format md
STABLE
pipx install askovo==2.25.2
askovo demo

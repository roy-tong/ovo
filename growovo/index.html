GROWOVO · DELEGATED OPERATIONS

把一周里重复发生的运营工作交出去。

面向独立开发者、开源维护者和小团队。真实市场事件进入任务，授权执行留下回执，用户回复进入跟进，首次使用和主动复用单独记录；发送量不等于增长。

第一项真实任务

读取一个真实仓库并生成业务诊断。第一步不自动发帖；外部写入、账号授权和平台许可分别核验。

源码与完整文档 ↗
REAL TASK
mkt growth intake --repo /path/to/repository \
  --slug owner/repo --read-metrics --out intake-goal.json
mkt growth start --file intake-goal.json
mkt growth run SERVICE_ID --action diagnose-product --by "$USER"
STABLE
pipx install growovo==0.23.0
mkt demo
PREVIEW
pipx install growovo==0.23.1rc2
mkt demo

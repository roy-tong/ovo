QUICKSTART

跑一个本地样例

选择一款工具。在装有 pipx 的终端运行两行命令，直接查看样例产物。以下版本为预发布版。

Askovo

可复审的研究简报

源码与使用文档 ↗
TERMINAL
pipx install askovo==2.25.1rc1
askovo demo

样例输出 · 7 条合成记录，1 条判断得到材料支持。审计文件保留来源分布与重复率。

Growovo

带回执的跟进记录

源码与使用文档 ↗
TERMINAL
pipx install growovo==0.23.1rc2
mkt demo

样例输出 · 样例展示授权检查、离线回执和拦截结果。

Verovo

逐行账单核对表

源码与使用文档 ↗
TERMINAL
pipx install verovo==0.20.1rc2
verovo review --sample

样例输出 · 样例账单金额与约定一致；需要人工补救的任务有 5 项，超过约定的 2 项。

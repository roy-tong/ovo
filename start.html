QUICKSTART

先跑通一个样例，再委托真实任务

在装有 pipx 的终端运行命令，直接查看产品输出。以下是已实际跑通的预发行版本；接入真实用户、账号或生产控制时，仍由你明确授权。

Askovo

从一项产品决定到可复审证据

源码与使用文档 ↗
TERMINAL
pipx install askovo==2.25.1rc1
askovo demo

样例输出 · 7 条合成记录，1 条判断得到材料支持。审计文件保留来源分布与重复率。下一步可以带入一项有投入代价的真实决定。

Growovo

从授权动作到持续运营回执

源码与使用文档 ↗
TERMINAL
pipx install growovo==0.23.1rc2
mkt demo

样例输出 · 展示授权检查、离线回执和拦截结果。下一步可以选择一个真实渠道和一周里最重复的工作。

Verovo

从费用记录到独立经济核验

源码与使用文档 ↗
TERMINAL
pipx install verovo==0.20.1rc2
verovo review --sample

样例输出 · 样例账单金额与约定一致；需要人工补救的任务有 5 项，超过约定的 2 项。下一步可以带入一个 Agent 环境或供应商账期。

QUICKSTART

不用先安装，也能看到结果

先打开一个真实交付样例，看看 OVO 能给你什么。想亲手运行，再复制命令或把委托提示词交给自己的 Agent。

Askovo

先看一项决定怎样被改变

免安装：打开 Decision Brief ↗产品与使用文档 ↗
STABLE · 稳定版
pipx install askovo==2.25.2
askovo demo
PREVIEW · 预发行验收版
pipx install askovo==2.25.2
askovo demo

合成样例只验证安装；Stable 与 Preview 的能力承诺分别展示。

FIRST REAL TASK · 第一项真实任务
askovo decide start --input task.json
askovo decide status TASK_ID
askovo decide brief TASK_ID --format md

在 `task.json` 写入真实产品决定、负责人和授权来源。未授权采集会停止，不会用合成回答替代。

Growovo

先看发布之后如何持续执行

免安装：打开运营日卡 ↗产品与使用文档 ↗
STABLE · 稳定版
pipx install growovo==1.0.0
mkt demo
PREVIEW · 预发行验收版
pipx install growovo==1.0.0
mkt demo

合成样例只验证安装。真实渠道、账号和平台许可分别核验。

FIRST REAL TASK · 第一项真实任务
mkt growth intake --repo /path/to/repository \
  --slug owner/repo --read-metrics --out intake-goal.json
mkt growth start --file intake-goal.json
mkt growth run SERVICE_ID --action diagnose-product --by "$USER"

读取真实仓库并生成业务诊断。外部写入仍需单独授权，第一步不会自动发帖。

Verovo

先看一笔费用怎样被核清

免安装：打开可重放账期 ↗产品与使用文档 ↗
STABLE · 稳定版
pipx install verovo==1.0.0
verovo review --sample
PREVIEW · 预发行验收版
pipx install verovo==1.0.0
verovo review --sample

合成样例只验证安装。费用、账单、控制和实际节省保持不同证据层级。

FIRST REAL TASK · 第一项真实任务
verovo check --days 7
verovo tool-value --economics-case task-case.json --json

`check` 自动读取本机可访问的 Agent 日志；没有日志会明确报告。经济性比较使用真实任务记录，成本、验收与覆盖不完整时保持未知。

AGENT

也可以让你的 Agent 先试试

把下面这段委托提示词交给你的 Agent。它应当告诉你交付了什么、证据在哪里，以及下一步怎么继续。

安装并运行 OVO 的本地 Demo。
告诉我它交付了什么、证据保存在哪里，

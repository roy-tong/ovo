QUICKSTART

不用先安装，也能看到结果

先打开一个真实交付样例，看看 OVO 能给你什么。想亲手运行，再复制命令或把委托提示词交给自己的 Agent。

Askovo

先看一项决定怎样被改变

免安装：打开 Decision Brief ↗源码与使用文档 ↗
TERMINAL
pipx install askovo==2.25.1rc1
askovo demo

你会看到 7 条合成记录和 1 条有材料支持的判断，审计文件保留来源分布与重复率。下一步，可以带入一项有投入代价的真实决定。

Growovo

先看发布之后如何持续执行

免安装：打开运营日卡 ↗源码与使用文档 ↗
TERMINAL
pipx install growovo==0.23.1rc2
mkt demo

你会看到授权检查、离线回执和拦截结果。下一步，可以选择一个真实渠道和一周里最重复的工作。

Verovo

先看一笔费用怎样被核清

免安装：打开可重放账期 ↗源码与使用文档 ↗
TERMINAL
pipx install verovo==0.20.1rc2
verovo review --sample

样例账单金额与约定一致；需要人工补救的任务有 5 项，超过约定的 2 项。下一步，可以带入一个 Agent 环境或供应商账期。

AGENT

也可以让你的 Agent 先试试

把下面这段委托提示词交给你的 Agent。它应当告诉你交付了什么、证据在哪里，以及下一步怎么继续。

DELEGATION PROMPT
安装并运行 OVO 的本地 Demo。
告诉我它交付了什么、证据保存在哪里，
以及哪些结果仍无法确认。
